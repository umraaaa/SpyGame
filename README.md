# 音樂臥底 🎶🕵️

派對遊戲：多數人拿到「平民的歌」，臥底拿到「臥底的歌」，戴耳機同時聽完後靠描述、哼唱找出臥底。

開房時可選兩種玩法：
- **🎵 歌曲臥底**：出題是選歌（iTunes 搜尋＋試聽＋提示），上台戴耳機聽 30 秒 preview，播完進討論
- **✏️ 單詞臥底**：出題是填兩個詞，上台倒數後亮出自己的詞，全員按「看好了」才進討論；複盤改為顯示該參加者拿到的詞

## 部署（GitHub Pages）

純靜態三個檔案（`index.html` / `style.css` / `app.js`），推上 repo 開啟 Pages 即可，不需要任何後端或 NAS。

## 架構

- **連線**：PeerJS 點對點。開房的人（房主）的裝置就是主機，其他人輸入 4 碼房號直連。房主關掉網頁房間就消失。
- **iTunes 搜尋 / 試聽**：全部在每個人自己的裝置上以 JSONP 呼叫 iTunes Search API，只有選定歌曲的 preview url 會傳給房主。
- **狀態**：房主持有唯一狀態，依身分裁切後推給每個人（自己的題目、自己被分到的歌只有自己看得到）。

## 流程

1. 大廳集合、按準備 → 房主開始遊戲
2. 所有人到「點歌」分頁出題（平民歌 + 臥底歌，各可加提示），隨時可改
3. 房主開始回合：隨機抽一組題目 → 抽全員 30%（無條件進位）上台（出題者除外）→ 其中隨機一人是臥底
4. 參加者戴耳機按準備 → 倒數 3 秒 → 同時播放各自的歌
5. 播完進入討論，時間不限；房主可對每位參加者按「複盤」讓所有裝置播出他聽到的歌
6. 房主按「下一輪」（有確認），該題作廢、出題者重新出題

## 已知限制（prototype）

- 房主或玩家重新整理頁面 = 離開房間，沒有斷線重連
- 沒有計分系統、沒有投票機制（口頭討論即可）
- 有人卡住時不會自動跳過：準備階段與播放階段房主都有「強制推進」按鈕（含確認）
